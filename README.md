&gt; 基于 Kaggle Olist Brazilian E-Commerce Dataset，围绕"用户价值分层"和"复购行为预测"两个业务问题，完成从多表数据处理、用户行为分析、RFM 用户分层到机器学习建模的完整数据分析项目。

## 🎯 业务问题

电商平台在获取新用户的同时，需要进一步识别高价值用户、降低用户流失，并针对潜在复购用户进行精准运营。

本项目重点回答两个问题：

**问题一：用户价值如何分层？**

基于用户历史交易数据构建 RFM 指标，通过 KMeans 聚类识别不同价值层级用户，并分析不同用户群体的行为特征。

**问题二：哪些用户更可能复购？**

基于用户历史交易行为构建特征，预测用户在未来 6 个月内是否再次购买，为营销名单筛选和用户运营提供数据依据。

## 📊 核心结论

**用户分层（RFM + KMeans，K=4）**：新客与潜力活跃用户 59.44%、沉睡用户 37.44%、高频次用户 3.10%、大额客单用户 0.03%——超 96% 用户仅单次购买，平台整体复购率较低，因此新客复购转化和沉睡用户召回具有较高的运营价值。

**复购预测**：Random Forest 准确率最高（0.8530），Logistic Regression 召回率最高（0.3233）。在 82.7:1 的类别不平衡下，高准确率具有欺骗性——Random Forest 漏报了 83% 的真实复购用户，因此业务场景应优先参考召回率

**核心驱动因素**：平均订单金额 &gt; 总消费金额 &gt; 购买间隔（两模型特征重要性结论一致）。

**运营建议**：大额客单用户配专属客服与优先配送；高频用户建会员积分体系；沉睡用户低成本优惠券召回；新客推首购复购激励与个性化推荐。

---
## ⚠️ 局限性

- 正负样本 82.7:1，尽管采用类别加权策略，模型对少数类的判别能力仍受限
- 仅使用 8 项交易行为特征，未纳入浏览/加购/评价等互动数据及促销、季节等外部变量
- 数据时间截止 2018 年，历史窗口约 18 个月，难以捕捉用户全生命周期演变
